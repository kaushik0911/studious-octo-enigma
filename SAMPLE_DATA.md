### DMS Number

This number is a uniq ID. The format is like this,

PMO/2026/06/19/237352

PMO/{received year}/{received month}/{received date}/{6 digit random number}

### Item Code

This is also a uniq number. And it is similar to this,

PVT-26M5-0001

* PVT - Branch (for now always 'PVT')
* 26 - First published year
* 2 - Type number
* 5 - Category number
* 0001 - Database sequence number
